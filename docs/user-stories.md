# User Stories

## Color Picking
- **US-001** As a user, I want to drag a color picker slider so that I can visually select any color I need.
- **US-002** As a user, I want to type a hex code into an input field so that I can jump directly to a specific color.
- **US-003** As a user, I want to see the RGB and HSL values update automatically when I pick a color so that I always know the exact color data.
- **US-004** As a user, I want a large live preview swatch so that I can clearly see the selected color before saving it.

## Copy & Export
- **US-005** As a user, I want to click a "Copy HEX" button so that I can quickly paste the color value into my design tool.
- **US-006** As a user, I want to copy the color as an RGB or HSL string so that I can use it directly in my CSS code.
- **US-007** As a user, I want to see a toast notification after copying so that I know the action was successful.

## Palette Management
- **US-008** As a user, I want to click a "Save Color" button so that I can add the current color to my personal palette.
- **US-009** As a user, I want to optionally give a saved color a name so that I can remember what I use it for.
- **US-010** As a user, I want to view all my saved colors in a grid so that I can browse my palette at a glance.
- **US-011** As a user, I want to click a saved color swatch so that it loads back into the picker and I can adjust or copy it.
- **US-012** As a user, I want to delete a color from my palette so that I can keep it clean and relevant.

## Accessibility & Detail
- **US-013** As a user, I want to see the contrast ratio of my selected color against white and black so that I can make accessible color choices.
- **US-014** As a user, I want the app to work well on mobile so that I can pick colors on any device.
- **US-015** As a user, I want a dark mode option so that I can use the app comfortably in low-light environments.
