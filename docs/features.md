# Features

## Color Picking
- Interactive color wheel and hue/saturation/brightness sliders
- Real-time color preview swatch
- Input fields for manual hex, RGB, and HSL entry
- Instant conversion between all color formats (HEX, RGB, HSL, RGBA)

## Copy & Export
- One-click copy to clipboard for any color format
- Visual feedback (toast notification) on successful copy
- Copy as CSS variable format (e.g. `--color-primary: #ff5733`)

## Palette Management
- Save any picked color to personal palette with optional custom name
- View all saved colors in a responsive grid
- Delete individual colors from palette
- Persistent storage via Supabase database

## Color Display
- Large live preview swatch that updates in real time
- Display complementary color suggestion
- Show color contrast ratio against black and white (WCAG accessibility hint)

## UI / UX
- Fully responsive layout with Tailwind CSS
- Dark mode support
- Smooth transitions and hover effects on palette swatches
